# TikTok — русские тексты для app-install рекламы (GizliAlan)

Черновик для TikTok Ads Manager (App Install). Длина рекламных текстов ≤ 100
символов (как в задании). Рядом — турецкий перевод для владельца.

**Отображаемое имя / Display name:** `GizliAlan`  
**CTA (кнопка):** `Установить` / Install (в Ads Manager: *Install* / *Download*)

## 3 текста (RU ≤ 100 символов) + TR

1. **RU:** Личный сейф на телефоне: фото и файлы под PIN, без облака.  
   *(78 символов)*  
   **TR:** Telefonda kişisel kasa: fotoğraflar ve dosyalar PIN ile, bulutsuz.

2. **RU:** Калькулятор снаружи, сейф внутри. Шифрование на устройстве.  
   *(72 символа)*  
   **TR:** Dışarıda hesap makinesi, içeride kasa. Cihazda şifreleme.

3. **RU:** Спрячьте фото и заметки. Без аккаунта — данные остаются у вас.  
   *(78 символов)*  
   **TR:** Fotoğrafları ve notları gizleyin. Hesap yok — veri sende kalır.

## Честное примечание: таргетинг на Россию

**По состоянию на октябрь 2026 TikTok Ads Manager не позволяет показывать
рекламу аудитории внутри России** и не даёт выбрать Россию как гео таргетинга.
Ограничение действует с марта 2022 (заморозка постинга и рекламы в РФ со
стороны TikTok); обходные схемы нарушают правила площадки и рискуют баном
кабинета.

- Источник (обзор CIS / РФ, актуальная формулировка «реклама в РФ не
  работает»):  
  https://dailyintelservice.com/markets/tiktok-ads-in-cis-where-it-runs-and-where-it-does-not  
- Доп. проверка на 2026-10-19 (RU):  
  https://luxaccs.com/blog/reklama-v-tiktok-iz-rossii-2026/

**Практический вывод для GizliAlan:** русскоязычные тексты выше можно
использовать для **других** доступных гео (например Казахстан / Узбекистан),
где русский язык понимают и TikTok Ads доставляет показы. Для **аудитории
внутри РФ** надёжнее Yandex Direct + AppMetrica, а не TikTok. Перед запуском
всегда сверяйте живой выпадающий список стран в своём Ads Manager — список
рынков зависит от страны регистрации кабинета.

iOS ATT не применяется (приложение только Android).
